# Приоритеты рефакторинга

## 🚨 Критичные модули (ядро бизнес-логики)

### 1. `tg_bot/handlers/coach_registration.py`
**Почему критично:** Регистрация пользователей, сбор данных (вес, рост, пол), настройка тренировок
**Зависимости:** 
- БД (`sqlite.py`) 
- FSM состояния
- Конфигурация бота
**Риски:** Сложная валидация, смешана бизнес-логика и телеграм-хендлеры

### 2. `tg_bot/handlers/coach_workout.py` 
**Почему критично:** Основной процесс тренировки, подбор упражнений, расчет нагрузок
**Зависимости:**
- БД упражнений и пользователей
- Система состояний (FSM)
- Логика рекомендаций
**Риски:** Самая сложная бизнес-логика, напрямую влияет на UX

### 3. `tg_bot/database/sqlite.py`
**Почему критично:** Вся работа с данными, миграции схемы
**Зависимости:** ВСЕ модули бота
**Риски:** SQLite не для продакшена, сырые SQL-запросы, нет миграций

## 🟡 Рискованные модули (требуют внимания)

### 4. `tg_bot/daemons/life_calendar.py`
**Проблемы:** Фоновая задача без мониторинга, может "умереть" тихо
**Влияние:** Пользователи не получат календари жизни

### 5. `bot.py`
**Проблемы:** Монолитная точка входа, смешана инициализация и бизнес-логика
**Влияние:** Сложно тестировать, добавлять новые функции

### 6. `tg_bot/utils/life_calendar.py`
**Проблемы:** Генерация изображений - ресурсоемко, может падать
**Влияние:** Ключевой фичей продукта
